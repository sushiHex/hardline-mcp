# ping-pong

The lanes take turns on one artifact (an idea, a design, a plan), each
challenging and adding to the last. With more than two lanes the turn passes
around the group in a fixed order.

## Run it

1. **You hold the artifact** in one file outside the workdir, and save each
   returned version.
2. **First turn, blind.** Lane A drafts, or attacks your starting draft.
3. **Each later turn** goes to the next lane with the artifact as it now stands
   and the previous turn's challenges. The brief asks it to:
   - challenge something, with a reason, or state plainly that nothing is
     left to challenge;
   - add or improve something, or say nothing needs it;
   - return the revised artifact, and say whether it agrees with that version.
4. Between turns you may correct factual errors against source. Say so in the
   next brief; don't silently edit.
5. **Stop at the first of:**
   - a full round that leaves the artifact unchanged. That is consensus if
     every lane said it agrees with this version; record what is unsettled;
   - the round limit.
6. **Decide.** Report how it stopped.

A lane that fails twice ends the play; report the artifact as it stood.
